What happens next?

  1. Your browser may ask to open Codex. Allow it.
  2. A new chat opens with the installation request filled in. Press Send.
  3. Let Codex download and install the existing pet files. Approve file access if requested.
  4. Choose your new companion in Settings → Pets.

The Codex desktop app must already be installed. Each button prepares a request for one pet; it does not send the request or install automatically. No downloaded installer script is needed.

If nothing opens, try this page in Safari or Chrome on the Mac or PC where Codex is installed.
