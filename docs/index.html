Manual installation · Mac & Windows

Download both pets as a ZIP ↗ and extract it.

macOS

  1. Extract the ZIP and open its pets folder.
  2. In Finder, press ⌘⇧G and enter ~/.codex/.
  3. Copy cheese and cream into the pets folder. Create it if missing. Back up matching folders before replacing them.
  4. Restart Codex and choose your companion in Settings → Pets.

Windows

Copy the same folders into %USERPROFILE%\.codex\pets\ in File Explorer, creating the destination if needed. Back up matching folders before replacing them. Restart Codex and choose your pet in Settings.

Keep pet.json and spritesheet.webp together inside each pet folder. Custom CODEX_HOME? Use its pets directory. A desktop app with custom pet support is required.
