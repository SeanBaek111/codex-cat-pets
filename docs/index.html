Installer did not open?

Your browser may ask for permission to open Codex. If the app opens without an installation window, use the manual steps below. Downloading the files alone does not install the pets.

Download both pets as a ZIP

macOS: install with Finder

  1. Download and extract the ZIP. Open its pets folder to find cheese and cream.
  2. In Finder, press ⌘⇧G (Go to Folder), enter ~/.codex/, and press Return.
  3. Open the pets folder, or create it if it is missing. Copy the cheese and cream folders into it. If folders with those names already exist, back them up before replacing them.
  4. Fully quit and reopen Codex, then choose Cheese or Cream in Settings → Pets.

No installer script or Terminal command is needed. The final files should be ~/.codex/pets/cheese/pet.json and ~/.codex/pets/cheese/spritesheet.webp, with the same structure for cream.

Windows

Extract the ZIP, open %USERPROFILE%\.codex in File Explorer, and copy the cheese and cream folders into its pets folder (create it if missing). Back up existing folders with the same names before replacing them. Restart Codex and choose your pet in Settings.

Using the individual files

Right-click each file link above and choose Save Link As. Keep the original filenames pet.json and spritesheet.webp together inside a folder named cheese or cream, then copy that folder to the same destination.

A desktop app with custom pet support is required. If you use a custom CODEX_HOME, use its pets folder instead. On Windows, use the Windows home directory, not a WSL directory.
